Where and what
Laptop: a real PostgreSQL on this computer; both copies share one disk and there is no network, so it shows the protocol working, not network speed. Cloud: source and destination are separate VMs in different zones, so the network and disks are real; the VMs are deleted when the run ends.
Which tools race. pg_basebackup is the baseline: PostgreSQL's own full copy. pgdelta refreshes the old copy by sending only the chunks that changed.
